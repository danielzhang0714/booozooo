# Iber Landing Page

## Overview

**Iber Landing Page** is a front-end web page project built with HTML, CSS, and JavaScript.  
The project focuses on creating a clean webpage layout with a header navigation bar, responsive page structure, external styling, JavaScript connection, and organized asset folders.

This project was created to practice basic front-end development skills, including semantic HTML structure, CSS layout design, JavaScript file organization, and responsive web page setup.

---

## Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **Responsive Web Design**
- **VS Code**
- **Git / GitHub**

---

## Features

- Clean HTML document structure
- Responsive viewport setup for different screen sizes
- Header section with website title and navigation items
- Navigation menu with:
  - Contact Us
  - About
  - Login button
- External CSS file for styling
- External JavaScript file connected with `defer`
- Custom favicon support
- Organized project folders for assets, styles, scripts, and media
